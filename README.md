# Event Ticket Sales Monitor // Live Ticketing & Sales Dashboard UI

A high-performance, real-time dashboard and UI portfolio concept engineered for event organizers, ticketing platforms, and live box office analytics. Built with a sleek dark-mode studio aesthetic and responsive architecture.

---

## Key Architectural Features
- **Live Ticketing Aesthetic:** High-contrast dark-mode interface featuring dynamic revenue summary cards, ticket inventory tracking, and sales performance metrics.
- **Pure Vanilla JavaScript & Tailwind:** Zero heavy dependencies to guarantee lightning-fast page loading and rapid DOM manipulation.
- **Fully Responsive Layout:** Seamlessly optimized across mobile, tablet, and high-resolution desktop viewports.

---

##  Technology Stack
- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Tailwind CSS (Utility-first framework)
- **Scripting:** Pure Vanilla JavaScript (ES6+)
